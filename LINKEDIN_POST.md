🌍 Just built EcoSense for #PromptWarsVirtual Challenge 3 — Carbon Footprint Awareness Platform!

The brief said "awareness" — not just tracking. That one word changed everything.

Awareness isn't a number on a dashboard. It's when data makes you feel something and actually changes what you do next. So I built around that.

Here's what EcoSense does differently:

🌏 **Living World Visualizer** — Your carbon score becomes an animated SVG planet. Fly every week → sky turns grey. Take the metro → trees grow. When consequences are visual and alive, they stick.

🤖 **Gemini AI Insights** — Not generic tips. Gemini reads your actual transport/food/energy/shopping numbers and tells you exactly what to change first, with estimated kg savings.

📊 **Real Context via Google Charts** — Your emissions vs India average vs Global average. Data without context changes nothing. Context changes everything.

🏆 **Community Challenges + Leaderboard** — Meatless Monday, Public Transport Week, Plant a Tree. Collective accountability is the most proven driver of behavior change.

🗺️ **Actionable Nudges + Google Maps** — Shows parks and cycling paths near you. Behavioral change needs accessible alternatives, not just guilt trips.

**Full Tech Stack:**
→ React + Vite + Tailwind CSS
→ FastAPI + Python backend
→ Firebase Auth + Firestore + Analytics
→ Google Gemini AI 1.5 Flash
→ Google Charts (Pie + Bar) + Maps Embed + Google Fonts
→ Playwright tests: 8/8 passing
→ Deployed on Vercel + Render

**Prompt Strategy:**
Built in 5 phases — each prompt owned one complete vertical slice. Every prompt included explicit fallback logic so the app works even without live API keys during evaluation.

Key learning: the best prompts don't ask for features. They specify inputs, outputs, fallback behavior, and edge cases. The AI fills the rest.
